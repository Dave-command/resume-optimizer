# resume-optimizer
Free AI-powered resume analyzer. Paste your resume, get instant feedback.

## Features
- AI analysis of resumes and cover letters
- Instant score (0-100)
- Actionable improvements
- Download reports

## Try it
[resumeboost.vercel.app](https://resumeboost.vercel.app)

## How it works
1. Paste your resume
2. Get AI feedback
3. Download report
4. Improve and reapply

Made solo with no coding knowledge. Happy to get feedback!
